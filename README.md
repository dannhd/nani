# Spider Date

Experiencia web responsive de estética pixel-art inspirada en una aventura arácnida por Nueva York.

## Abrir directamente

Abre `index.html` en cualquier navegador moderno. La versión independiente usa solamente HTML, CSS y JavaScript.

## Desarrollo y despliegue

```bash
npm install
npm run dev
```

Para comprobar la versión lista para publicar:

```bash
npm test
```

La imagen de referencia se guarda localmente en `assets/`; no se cargan imágenes externas.
